What it will cover

File formats, read and written as the references do.

Every item starts from the roadmap's bibliography, is validated against the tool that is the reference in its domain, and lands with tests at 100% coverage and a performance table: no slower than the reference on one core.

🗄️

HDF5

Reader and writer for the File Format Specification 3.0, the base of MAT v7.3 and NetCDF-4. Whether it wraps an audited package or is written here is still open.

🧮

MAT-files

Versions 4, 5, 7 and 7.3, the last on top of the HDF5 package.

🌍

NetCDF

Classic (CDF-1, 2, 5) and NetCDF-4, with the CF conventions' units.

🔭

FITS

FITS 4.0: images, binary tables and compressed images.

🔢

npy and Matrix Market

NumPy .npy and .npz; Matrix Market coordinate and array files.

🎧

Audio

WAV, and FLAC decoding (RFC 9639).

🛡️

Hostile input

Fuzzing and a limit on the allocation a header can ask for, in line with the fleet's decompression-bomb standard.

📦

Pure Go, CGO=0

No cgo on any architecture the fleet's CI tests. The C libraries are oracles, never dependencies.
